# 准备插件开发环境并着手开发

#### 【PART 1】准备插件开发环境

##### 一、创建插件工程

以创建一个路由插件为例，步骤如下：

- 在Flutter工程目录（MyCookBook_FlutterPlugin）下创建plugins文件夹，以后各种插件都放到此文件夹下。
- cd到这个plugins文件夹中，执行命令：

```text
hflutter create --org com.lihao.cookbook.flutter_router --template=plugin --platforms=ohos,android,ios flutter_router
```

注：此处依然是使用定制版Flutter SDK中的`hflutter`来操作。

这里创建了一个名为`flutter_router`的路由插件，支持鸿蒙、安卓、苹果平台，并且指定了插件包名是`com.lihao.cookbook.flutter_router`。

由此可见如果要支持多个平台，在命令的`--platforms`参数中以逗号分割指定即可。

##### 二、补充插件支持的平台

上一节指定了插件支持的平台是鸿蒙、安卓、苹果三个，当然也可以仅指定一个平台，或者先不指定任何平台：

```text
hflutter create --org com.lihao.cookbook.flutter_router --template=plugin flutter_router
```

##### 三、删除插件支持的平台

如果想删除对某个平台的支持，到对应插件文件夹中，删除平台文件夹即可。此外example文件夹中对应平台的示例文件夹也需要被删除。

##### 四、集成插件

插件创建完毕后记得在MyCookBook_FlutterPlugin工程的pubspec.yaml中添加引用：

```text
...
dependencies:
  flutter:
    sdk: flutter

  # The following adds the Cupertino Icons font to your application.
  # Use with the CupertinoIcons class for iOS style icons.
  cupertino_icons: ^1.0.6

  flutter_router: 
    path: plugins/flutter_router
...
```

#### 【PART 2】开发Flutter路由插件

1.  在刚创建的flutter_router插件工程中，可以创建一个路由管理器，用来记录路由路径、参数与Flutter页面的对应关系。dart代码如下：

```text
import 'dart:convert';
import 'package:flutter/widgets.dart';

/// Widget构造方法，接收任意类型参数[params]。
typedef RouterWidgetBuilder = Widget Function(dynamic params);

/// flutter路由管理器。
/// @author li.hao85
class RouterManager {
  RouterManager._();

  static final RouterManager _instance = RouterManager._();

  static RouterManager get instance => _instance;

  /// 路由路径与Widget构造方法的对应Map。
  final Map<String, RouterWidgetBuilder> _routerMap = {};

  /// 添加新的路由路径[path]与对应的Widget构造方法[routerWidgetBuilder]。
  bool addRouter(String path, RouterWidgetBuilder routerWidgetBuilder) {
    _routerMap[path] = routerWidgetBuilder;
    return true;
  }

  /// 根据路由信息[routerInfo]查询对应的Widget构造方法并返回。
  ///
  /// 当路由信息[routerInfo]不带参数时，尝试给对应的Widget构造方法传递默认参数[defaultParams]。
  ///
  /// 注：如果路由信息不对应任何Widget构造方法，那么会返回一个Container空容器。
  Widget getRouterWidget(String routerInfo, {Object? defaultParams}) {
    final String path = _getRouterPath(routerInfo);
    Object? params = _getRouterParams(routerInfo);
    RouterWidgetBuilder? routerWidgetBuilder = _routerMap[path];
    if (routerWidgetBuilder != null) {
      return routerWidgetBuilder(params ?? defaultParams);
    } else {
      return Container();
    }
  }

  /// 从路由信息[routerInfo]中解析出路径信息。
  ///
  /// 路由格式暂定为`path?params`，其中path是路由的路径信息，params是路由参数。路由参数是一个json字符串，路径信息与路由参数之间用问号分割。
  String _getRouterPath(String? routerInfo) {
    if (routerInfo == null) {
      return '/';
    }
    if (routerInfo.contains('?')) {
      Uri uri = Uri.parse(routerInfo);
      return uri.path;
    } else {
      return routerInfo;
    }
  }

  /// 从路由信息[routerInfo]中解析出路由参数。
  ///
  /// 路由格式暂定为`path?params`，其中path是路由的路径信息，params是路由参数。路由参数是一个json字符串，路径信息与路由参数之间用问号分割。
  Object? _getRouterParams(String? routerInfo) {
    if (routerInfo == null) {
      return null;
    }
    if (routerInfo.contains('?')) {
      Uri uri = Uri.parse(routerInfo);
      String query = uri.query;
      try {
        query = Uri.decodeFull(query);
        return json.decode(query);
      } catch (error) {
        return Uri.splitQueryString(query);
      }
    } else {
      return null;
    }
  }
}

```

2.  增加一个Flutter测试页面，用来展示接收到的参数：

```text
import 'dart:convert';

import 'package:flutter/material.dart';

class LoginPage extends StatefulWidget {
  const LoginPage({Key? key, this.params}) : super(key: key);

  final Map<String, dynamic>? params; // 前一页传递过来的参数。

  @override
  State<StatefulWidget> createState() {
    return _LoginState();
  }
}

class _LoginState extends State<LoginPage> {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
        appBar: AppBar(centerTitle: true, title: const Text('登录页面')),
        body: Center(
            child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: <Widget>[
              const Text('登录页面获取到的参数', style: TextStyle(fontSize: 16)),
              Text(jsonEncode(widget.params))
            ])));
  }
}
```

3.  对Flutter工程根目录lib文件夹下的main.dart进行修改，使之能够接收HarmonyOS工程传递过来的路由路径、参数，并跳转至上一小节的测试页面：

```text
import 'package:flutter/foundation.dart';
import 'package:flutter/material.dart';
import 'package:flutter_router/router_manager.dart';
import 'package:my_cook_book_flutter_plugin/login_page.dart';

void main() {
  _initRouters();
  var pathInfo = PlatformDispatcher.instance.defaultRouteName; // 从具体平台处接收传递过来的参数。
  runApp(MyApp(pathInfo: pathInfo));
}

class MyApp extends StatelessWidget {
  const MyApp({Key? key, required this.pathInfo}) : super(key: key);
  final String pathInfo;

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      theme: ThemeData(primarySwatch: Colors.blue),
      home: RouterManager.instance.getRouterWidget(pathInfo),
    );
  }
}

void _initRouters() {
  RouterManager.instance
      .addRouter('login_page', (params) => LoginPage(params: params));
}
```

4.  至此一个Flutter路由插件就创建好了，使用`hflutter build har --release`命令编译一下。
