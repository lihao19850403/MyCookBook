# Flutter页面携参返回HarmonyOS页面

从Flutter页面返回至HarmonyOS工程页面，还是需要用到MethodChannel来进行，具体操作步骤为：

1.  编写HarmonyOS平台特定返回方法(对`FlutterRouterPlugin`类进行修改)：

这里主要做了三件事：

- 定义一个HarmonyOS端的路由处理handler(`routerBackHandler`)，当有从Flutter页面返回HarmonyOS页面的动作时，交由此handler处理。
- 定义一个routerBackHandler的设置方法(`setRouterBackHandler()`)，HarmonyOS平台可以通过此方法手动设置一个routerBackHandler，默认进行原生页面的返回。
- 在`onMethodCall()`方法中定义了一个`back()`方法的处理过程，以后Flutter部分返回上一页都使用这个back()方法进行。

```text
import {
  FlutterPlugin,
  FlutterPluginBinding,
  MethodCall,
  MethodCallHandler,
  MethodChannel,
  MethodResult,
} from '@ohos/flutter_ohos';

/** Flutter路由跳转类型。 */
export type FlutterRouterPushHandler = (path: string, params: Record<string, Object> | undefined, result: MethodResult) => boolean;

/** Flutter路由返回类型。 */
export type FlutterRouterBackHandler = (call: MethodCall, params: Record<string, Object> | undefined, result: MethodResult) => boolean;

/** FlutterRouterPlugin **/
export default class FlutterRouterPlugin implements FlutterPlugin, MethodCallHandler {
  private channel: MethodChannel | null = null;

  /** Flutter路由跳转工具，默认不处理路由，返回false。主工程可自行修改为有意义的工具。 */
  static routerPushHandler: FlutterRouterPushHandler = (path, params, result) => {
    console.log(`FlutterRouterPushHandler 默认实现。路径：${path}，参数：${JSON.stringify(params)}`);
    return false;
  };

  /** Flutter路由返回工具，默认不处理路由，返回false。主工程可自行修改为有意义的工具。 */
  static routerBackHandler: FlutterRouterBackHandler = (call, params, result) => {
    console.log(`FlutterRouterBackHandler 默认实现。调用：${JSON.stringify(call)}，参数：${JSON.stringify(params)}`);
    return false;
  }

  constructor() {
  }

  /**
   * 设置Flutter路由跳转工具。
   * @param newHandler 新的路由跳转工具。
   */
  static setRouterPushHandler(newHandler: FlutterRouterPushHandler) {
    FlutterRouterPlugin.routerPushHandler = newHandler;
  }

  /**
   * 设置Flutter路由返回工具。
   * @param newHandler 新的路由返回工具。
   */
  static setRouterBackHandler(newHandler: FlutterRouterBackHandler) {
    FlutterRouterPlugin.routerBackHandler = newHandler;
  }

  getUniqueClassName(): string {
    return "FlutterRouterPlugin"
  }

  onAttachedToEngine(binding: FlutterPluginBinding): void {
    this.channel = new MethodChannel(binding.getBinaryMessenger(), "flutter_router");
    this.channel.setMethodCallHandler(this)
  }

  onDetachedFromEngine(binding: FlutterPluginBinding): void {
    if (this.channel != null) {
      this.channel.setMethodCallHandler(null)
    }
  }

  onMethodCall(call: MethodCall, result: MethodResult): void {
    if (call.method == "getPlatformVersion") {
      result.success("OpenHarmony ^ ^ ")
    } else if (call.method === 'go') {
      let path: string = call.argument('path');
      let params: Record<string, Object> | undefined = call.argument('params');
      FlutterRouterPlugin.routerPushHandler(path, params, result);
    } else if (call.method === 'back') {
      let params: Record<string, Object> | undefined = call.argument('params');
      FlutterRouterPlugin.routerBackHandler(call, params, result);
    } else {
      result.notImplemented()
    }
  }
}
```

2.  在Flutter插件工程中编写back()方法的实现：

- 首先在FlutterRouterPlatform中对back()方法进行了定义。dart代码是：

```text
import 'package:plugin_platform_interface/plugin_platform_interface.dart';

import 'flutter_router_method_channel.dart';

abstract class FlutterRouterPlatform extends PlatformInterface {
  ...
  void back({dynamic params}) {
    throw UnimplementedError('back() has not been implemented.');
  }
}
```

- 然后在MethodChannelFlutterRouter中对back()方法进行了实现。dart代码是：

```text
import 'package:flutter/foundation.dart';
import 'package:flutter/services.dart';

import 'flutter_router_platform_interface.dart';

/// An implementation of [FlutterRouterPlatform] that uses method channels.
class MethodChannelFlutterRouter extends FlutterRouterPlatform {
  ...
  @override
  void back({dynamic params}) async {
    var routerParams = {};
    if (params != null) {
      routerParams = params;
    }
    await methodChannel.invokeMethod('back', routerParams);
  }
}

```

- 最后在FlutterRouter中定义了一个back()方法，供Flutter工程代码调用。这个方法会判断要返回的目标页面类型。如果目标页面是Flutter页面，则使用Flutter的Navigator返回；否则就尝试使用原生方法返回。dart代码是：

```text
// You have generated a new plugin project without specifying the `--platforms`
// flag. A plugin project with no platform support was generated. To add a
// platform, run `flutter create -t plugin --platforms <platforms> .` under the
// same directory. You can also find a detailed instruction on how to add
// platforms in the `pubspec.yaml` at
// https://flutter.dev/docs/development/packages-and-plugins/developing-packages#plugin-platforms.

import 'package:flutter/material.dart';
import 'package:flutter_router/router_manager.dart';

import 'flutter_router_platform_interface.dart';

class FlutterRouter {
  ...
  /// 页面返回方法。
  ///
  /// 注：如果上一个页面是Flutter页面，则使用Flutter的Navigator跳转，需要借助布局上下文[context]；如果上一个页面是原生平台页面，那么就尝试跳转入原生页面。
  void back(BuildContext context, {Object? params}) {
    if (Navigator.of(context).canPop()) {
      Navigator.of(context).pop(params);
    } else {
      FlutterRouterPlatform.instance.back(params: params);
    }
  }
}

```

4.  HarmonyOS平台配置routerBackHandler：

由于引用了flutter_router.har，因此HarmonyOS工程可以调用里面的方法了。此处在EntryAbility初始化时登记一个页面返回路由handler：

```text
...
import FlutterRouterPlugin from 'flutter_router';
...
export default class EntryAbility extends UIAbility implements ExclusiveAppComponent<UIAbility> {
  onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
    ...
    // 声明平台特定的Flutter页面返回路由handler。
    FlutterRouterPlugin.setRouterBackHandler(flutterRouterBackHandler);
  }
}
```

其中flutterRouterBackHandler定义如下：

```text
import { MethodResult } from '@ohos/flutter_ohos';
import { LHWebBrowser, URL_PARAMS } from '../../pages/common/webbrowser/LHWebBrowser';

/**
 * 鸿蒙平台下的Flutter页面返回handler。
 * @param call 函数调用。
 * @param params 路由参数。
 * @param result 跳转结果，用于向Flutter页面返回参数。
 * @returns 处理是否完成。
 */
export const flutterRouterBackHandler: (call: MethodCall, params: Record<string, Object> | undefined, result: MethodResult) => boolean =
  (call, params, result) => {
    if (call.method === 'back') {
      let routerName: string | undefined = undefined;
      if (params !== undefined) {
        routerName = params instanceof Map ? params.get('router_name') as string : params['router_name'] as string;
      }
      if (routerName !== undefined) {
        RouterUtils.navBackTo(routerName);
      } else {
        RouterUtils.navBack();
      }
    }
    return true;
  };

```

其实这个handler走的就是Navigation的返回。
