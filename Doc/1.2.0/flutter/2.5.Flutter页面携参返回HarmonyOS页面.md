# Flutter页面携参返回HarmonyOS页面

从Flutter页面返回至HarmonyOS工程页面，还是需要用到MethodChannel来进行，具体操作步骤为：

1.  编写HarmonyOS平台特定返回方法：

代码位置是[MyCookBook_FlutterPlugin/plugins/flutter_router/ohos/src/main/ets/components/plugin/FlutterRouterPlugin.ets](../../../MyCookBook_FlutterPlugin/plugins/flutter_router/ohos/src/main/ets/components/plugin/FlutterRouterPlugin.ets)，这里主要做了三件事：

- 定义一个HarmonyOS端的路由处理handler(`routerBackHandler`)，当有从Flutter页面返回HarmonyOS页面的动作时，交由此handler处理。
- 定义一个routerBackHandler的设置方法(`setRouterBackHandler()`)，HarmonyOS平台可以通过此方法手动设置一个routerBackHandler，默认进行原生页面的返回。
- 在`onMethodCall()`方法中定义了一个`back()`方法的处理过程，以后Flutter部分返回上一页都使用这个back()方法进行。

2.  在Flutter插件工程中编写back()方法的实现：

- 首先在FlutterRouterPlatform中对back()方法进行了定义。代码位置是[MyCookBook_FlutterPlugin/plugins/flutter_router/lib/flutter_router_platform_interface.dart](../../../MyCookBook_FlutterPlugin/plugins/flutter_router/lib/flutter_router_platform_interface.dart)。
- 然后在MethodChannelFlutterRouter中对back()方法进行了实现。代码位置是[MyCookBook_FlutterPlugin/plugins/flutter_router/lib/flutter_router_method_channel.dart](../../../MyCookBook_FlutterPlugin/plugins/flutter_router/lib/flutter_router_method_channel.dart)。
- 最后在FlutterRouter中定义了一个back()方法，供Flutter工程代码调用。这个方法会判断要返回的目标页面类型。如果目标页面是Flutter页面，则使用Flutter的Navigator返回；否则就尝试使用原生方法返回。代码位置是[MyCookBook_FlutterPlugin/plugins/flutter_router/lib/flutter_router.dart](../../../MyCookBook_FlutterPlugin/plugins/flutter_router/lib/flutter_router.dart)。

3.  编译并引入back()方法：

- 记得给flutter_router添加HarmonyOS平台支持。这需要在其pubspec.yaml中添加如下配置信息：

```text
...
plugin:
    platforms:
    # This plugin project was generated without specifying any
    # platforms with the `--platform` argument. If you see the `some_platform` map below, remove it and
    # then add platforms following the instruction here:
    # https://flutter.dev/docs/development/packages-and-plugins/developing-packages#plugin-platforms
    # -------------------
      some_platform:
        pluginClass: somePluginClass
    # -------------------
      ohos: # 此处添加HarmonyOS平台支持，主要填写pluginClass。
        package: com.example.my_cook_book_flutter_plugin
        pluginClass: FlutterRouterPlugin
...
```

代码位置是[MyCookBook_FlutterPlugin/plugins/flutter_router/pubspec.yaml](../../../MyCookBook_FlutterPlugin/plugins/flutter_router/pubspec.yaml)。

- 接下来编译此插件。进入MyCookBook_FlutterPlugin根目录，执行命令：

```text
hflutter pub get
hflutter build har --release
```

编译完成后会在MyCookBook_FlutterPlugin/build/ohos/har/release中生成flutter_embedding_release.har、arm64_v8a_release.har、flutter_module.har和flutter_router.har。最后新生成的flutter_router.har包含了上述back()方法的实现。

注：随着鸿蒙版Flutter SDK的不断更新，编译产物有可能会发生变化，请以实际的编译产物为准。

- 最后在HarmonyOS工程中引入此har文件。代码位置是[MyCookBook_HarmonyOS/oh-package.json5](../../../MyCookBook_HarmonyOS/oh-package.json5)。
  **注意引用flutter_router.har时指定的key不是以@ohos开头的**。
  引用完毕后重编译一下HarmonyOS工程。

4.  HarmonyOS平台配置routerBackHandler：

由于引用了flutter_router.har，因此HarmonyOS工程可以调用里面的方法了。此处在EntryAbility初始化时登记一个页面返回路由handler：

```text
...
import FlutterRouterPlugin from 'flutter_router';
...
export default class EntryAbility extends UIAbility implements ExclusiveAppComponent<UIAbility> {
  onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
    ...
    // 声明平台特定的Flutter页面返回路由handler。
    FlutterRouterPlugin.setRouterBackHandler(flutterRouterBackHandler);
  }
}
```

其中flutterRouterBackHandler定义如下：

```text
import { MethodResult } from '@ohos/flutter_ohos';
import { LHWebBrowser, URL_PARAMS } from '../../pages/common/webbrowser/LHWebBrowser';

/**
 * 鸿蒙平台下的Flutter页面返回handler。
 * @param call 函数调用。
 * @param params 路由参数。
 * @param result 跳转结果，用于向Flutter页面返回参数。
 * @returns 处理是否完成。
 */
export const flutterRouterBackHandler: (call: MethodCall, params: Record<string, Object> | undefined, result: MethodResult) => boolean =
  (call, params, result) => {
    if (call.method === 'back') {
      let routerName: string | undefined = undefined;
      if (params !== undefined) {
        routerName = params instanceof Map ? params.get('router_name') as string : params['router_name'] as string;
      }
      if (routerName !== undefined) {
        RouterUtils.navBackTo(routerName);
      } else {
        RouterUtils.navBack();
      }
    }
    return true;
  };

```

其实这个handler走的就是Navigation的返回。
