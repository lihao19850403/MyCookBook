# HarmonyOS工程与Flutter框架交互

#### 概述

在上一篇文章[《HarmonyOS工程集成Flutter的过程》](1.HarmonyOS工程集成Flutter的过程.md)中，我为已有的HarmonyOS工程添加了Flutter开发框架。添加完毕后，HarmonyOS工程可以跳转至一个容器页（FlutterIndexPage），在这个容器页中通过加载FlutterPage控件来展示Flutter内容。

本文在此基础上，以创建一个路由插件的方式，进一步讨论HarmonyOS工程与Flutter代码的交互流程。

首先需要准备插件开发环境，为插件开发做准备：[准备插件开发环境并着手开发](2.1.准备插件开发环境并着手开发.md)。

HarmonyOS页面与Flutter页面的交互流程可概括如下：

```text
         ┏━━━━━━━(4)━━━━━━━━┓      ┏━━━━━━━(3)━━━━━━━┓
         ┃                  ┃      ┃                 ┃
┏━━━━━━━━┻━━━━━━━━━┓   ┏━━━━┻━━━━━━┻━━━━┓   ┏━━━━━━━━┻━━━━━━━━━┓
┃ HarmonyOS Page A ┃   ┃ Flutter Page A ┃   ┃ HarmonyOS Page B ┃
┗━━━━━━━━┳━━━━━━━━━┛   ┗━━━━┳━━━━━━┳━━━━┛   ┗━━━━━━━━┳━━━━━━━━━┛
         ┃                  ┃      ┃                 ┃
         ┗━━━━━━━(1)━━━━━━━━┛      ┗━━━━━━━(2)━━━━━━━┛
                                        
```

(2) [Flutter页面跳转至HarmonyOS页面](2.3.Flutter页面跳转至HarmonyOS页面.md)

(3) [HarmonyOS页面携参返回Flutter页面](2.4.HarmonyOS页面携参返回Flutter页面.md)
