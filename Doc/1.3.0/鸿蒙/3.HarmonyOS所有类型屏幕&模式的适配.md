# HarmonyOS所有类型屏幕&模式的适配

#### 概述

之前对直板屏、折叠屏、pad设备进行了适配，相关文档见[动态监听屏幕尺寸及状态改变](https://developer.huawei.com/consumer/cn/blog/topic/03162326904748004)。

这次准备对所有设备的屏幕、应用显示模式进行适配。期望达成的目标是：

- 适配直板屏、2折叠、3折叠、扩折叠(包括外屏)、pad、PC、TV。
- 适配应用在悬浮窗模式下的显示(拖拽改变悬浮窗尺寸时内容自动适配)。
- 适配分屏模式下的显示(用户拖动两个应用间分割线时，内容自动适配)。

Window类的某些监听有助于完成这些目标。

#### 监听研究

我们先把EntryAbility中的window保存下来备用：

```text
onWindowStageCreate(windowStage: window.WindowStage): void {
  // Main window is created, set main page for this ability
  hilog.info(0x0000, 'testTag', '%{public}s', 'Ability onWindowStageCreate');

  windowStage.loadContent('应用的起始页路径', (err) => {
    if (err.code) {
      hilog.error(0x0000, 'testTag', 'Failed to load the content. Cause: %{public}s', JSON.stringify(err) ?? '');
      return;
    }
    hilog.info(0x0000, 'testTag', 'Succeeded in loading the content.');

    // 记录window对象。
    let mainWindow: window.Window = windowStage.getMainWindowSync();
    GlobalConfig.set(GLOBAL_CONFIG_KEY_WINDOW, mainWindow);
  });
}
```

其中GlobalConfig是一个简单的键值对存储工具，当然用别的也行：

```text
export class GlobalConfig {
  private static mMap: Record<string, Object> = {};
  public static set = <T>(key: string, value: T) => GlobalConfig.mMap[key] = value as object;
  public static get = <T>(key: string) => GlobalConfig.mMap[key] as T;
}
```

##### 一、windowSizeChange

当屏幕尺寸改变的时候(不响应屏幕位置的改变)，会触发这个监听。**但在悬浮窗模式下，拖动应用窗口改变大小，并不会触发此监听！**因此这个监听的灵敏度不是很高。

好在屏幕硬件状态改变的时候，屏幕的尺寸也会改变，同样会触发这个监听。比如一个折叠屏设备打开、关闭屏幕时。当触发此监听后，我们可以查询当前设备屏幕处于怎样的状态：

1，首先定义几个屏幕硬件状态：

```text
/** 屏幕类型。 */
export const enum ScreenUIType {
  /** 直板单屏、折叠屏设备已合上、默认状态。 */ NORMAL = 0,
  /** 折叠屏设备已打开状态。 */ FOLD_OPENED = 1,
  /** 平板类型设备屏幕。 */ PAD = 2
}
```

2，准备一个屏幕硬件状态的查询方法：

```text
/**
 * 获取当前屏幕类型。
 * @returns 当前屏幕类型。
 */
export function getScreenUIType(): ScreenUIType {
  let deviceType = deviceInfo.deviceType;
  if (deviceType === 'tablet' || deviceType === 'tv' || deviceType === 'car' || deviceType === 'smartVision' || deviceType === '2in1') {
    return ScreenUIType.PAD;
  }
  let screenWidthPx = display.getDefaultDisplaySync().width;
  let screenHeightPx = display.getDefaultDisplaySync().height;
  let bigEdgeLength = Math.max(screenWidthPx, screenHeightPx);
  let smallEdgeLength = Math.min(screenWidthPx, screenHeightPx);
  let rate = bigEdgeLength / smallEdgeLength;
  if (canIUse('SystemCapability.Window.SessionManager')) {
    if (display.isFoldable() && display.getFoldStatus() !== display.FoldStatus.FOLD_STATUS_FOLDED) {
      if (rate > 1 && rate < 1.2) {
        return ScreenUIType.FOLD_OPENED;
      } else if (screenWidthPx > screenHeightPx) {
        return ScreenUIType.PAD;
      }
    }
  } else {
    if (rate > 1 && rate < 1.2) {
      return ScreenUIType.FOLD_OPENED;
    } else if (screenWidthPx > screenHeightPx) {
      return ScreenUIType.PAD;
    }
  }
  return ScreenUIType.NORMAL;
}
```

3，使用windowSizeChange监听：

```text
let mainWindow: window.Window = GlobalConfig.get(GLOBAL_CONFIG_KEY_WINDOW) as window.Window;
mainWindow.on('windowSizeChange', (windowSize: Size) => this.screenUIChangeAdapter());

/** 响应设备类型的变化。 */
private screenUIChangeAdapter() {
  let newScreenUIType = getScreenUIType();
  // 通知应用屏幕硬件状态已经变更为newScreenUIType。
}
```

##### 二、avoidAreaChange

当应用所处Window的安全区发生变化的时候，会触发此监听。比如在扩折叠设备上，当用户合上屏幕时，应用会显示在外屏，这个外屏是没有上下两个安全区的。

```text
let mainWindow: window.Window = GlobalConfig.get(GLOBAL_CONFIG_KEY_WINDOW) as window.Window;
mainWindow.on("avoidAreaChange", (options: window.AvoidAreaOptions) => this.avoidAreaChangeAdapter(options));

/**
 * 响应安全区的变化。
 * @param options 新的安全区信息。
 */
private avoidAreaChangeAdapter(options: window.AvoidAreaOptions) {
  let newAvoidAreaType = options.type;
  let newAvoidArea = options.area;
  // 通知应用屏幕安全区有改变。
}
```

上述代码中，newAvoidAreaType的取值有：TYPE_SYSTEM、TYPE_CUTOUT、TYPE_SYSTEM_GESTURE、TYPE_KEYBOARD、TYPE_NAVIGATION_INDICATOR；newAvoidArea表示对应类型区域的信息。

- 屏幕顶端安全区改变，newAvoidAreaType取值是TYPE_SYSTEM，newAvoidArea的topRect对应安全区高度。
- 屏幕底端安全区改变，newAvoidAreaType取值是TYPE_NAVIGATION_INDICATOR，newAvoidArea的bottomRect对应安全区高度。

有时候我们不想频繁通知应用屏幕安全区有改变，仅在newAvoidArea的矩形区域有变化时才通知，这时就要比较变化前后两个Rect的差异了。比较方法可以是这样的：

```text
/**
 * 比较两个矩形是否不同。
 * @param rectA 矩形A。
 * @param rectB 矩形B。
 * @returns 比较结果，true表示二者不同。
 */
export function diffRect(rectA?: window.Rect, rectB?: window.Rect): boolean {
  return rectA?.left !== rectB?.left ||
    rectA?.top !== rectB?.top ||
    rectA?.width !== rectB?.width ||
    rectA?.height !== rectB?.height;
}
```

##### 三、windowStatusChange

当应用所处Window的形态发生变化的时候，会触发此监听。比如应用从全屏变为悬浮窗模式，或者变为两应用分屏模式。

```text
let mainWindow: window.Window = GlobalConfig.get(GLOBAL_CONFIG_KEY_WINDOW) as window.Window;
mainWindow.on("windowStatusChange", (type: window.WindowStatusType) => this.windowStatusTypeChangeAdapter(type));

/**
 * 响应屏幕状态类型的改变。
 * @param type 新的屏幕状态类型。
 */
private windowStatusTypeChangeAdapter(type: window.WindowStatusType) {
  let newType = type;
  // 通知应用屏幕形态已变更为newType。
}
```

newType取值有：

- UNDEFINED：未指定，当应用还没有开始显示的时候是这个状态。
- FULL_SCREEN：应用全屏显示，大部分情况下是这个状态。
- MAXIMIZE：最大化窗口，适用于PC。
- MINIMIZE：最小化窗口，适用于PC。
- FLOATING：悬浮窗模式，手指从屏幕底端推动应用到右上方即可切换悬浮窗模式；PC设备默认以悬浮窗模式显示应用。
- SPLIT_SCREEN：双应用分屏模式，手指从屏幕底端推动应用到左上方即可切换此模式，如果此时再打开另外一个应用，两个应用间会有分隔条，用户可操作分隔条来控制应用占据屏幕的比例。

##### 四、windowRectChange

与windowSizeChange不同，这个监听既响应窗口尺寸的变化，也响应窗口位置的变化，灵敏度很高。**后期优化可考虑使用此监听替代windowSizeChange监听。**

在这个灵敏度极高的监听中，我们查询应用窗口是否到达预设的断点，特别是在双应用分屏模式下，或者PC设备的悬浮窗模式下，当应用所处Window的尺寸达到某个预设断点时，我们可以通知应用改变布局。

```text
let mainWindow: window.Window = GlobalConfig.get(GLOBAL_CONFIG_KEY_WINDOW) as window.Window;
mainWindow.on("windowRectChange", (options: window.RectChangeOptions) => this.windowSizeChangeAdapter(options));

/**
 * 响应屏幕断点的改变。
 * @param options 新的屏幕尺寸信息。
 */
private windowSizeChangeAdapter(options: window.RectChangeOptions) {
  // 查询屏幕断点需要使用当前页面的UIContext对象：
  let newWindowWidthBreakpoint = uiContext.getWindowWidthBreakpoint();
  let newWindowHeightBreakpoint = uiContext.getWindowHeightBreakpoint();
  // 通知应用屏幕的宽高断点达到了新的数值。
}
```

#### 集成

考虑把以上这些监听集成到一起，并且仅在状态发生改变的时候才通知应用做适配，这里我们再引入一个自定义的EventBus，整个工具类代码如下：

```text
/** 屏幕状态信息。 */
export interface ScreenStatusInfo {
  /** 设备类型。 */ screenUIType?: ScreenUIType;
  /** 安全区类型。 */ avoidAreaType?: window.AvoidAreaType;
  /** 安全区域信息。 */ avoidArea?: window.AvoidArea;
  /** 窗口类型。 */ windowStatusType?: window.WindowStatusType;
  /** 窗口宽方向断点类型。 */ windowWidthBreakpoint?: WidthBreakpoint;
  /** 窗口高方向断点类型。 */ windowHeightBreakpoint?: HeightBreakpoint;
}

/**
 * 监控屏幕状态改变的工具类。
 */
export class ScreenObserver {

  private static mInstance: ScreenObserver;

  /** 当前屏幕状态信息。 */
  private currentScreenStatusInfo: ScreenStatusInfo;

  /** 订阅者集合。 */
  private subscribers: HashMap<UIContext, Callback<ScreenStatusInfo, void>> = new HashMap();

  private constructor() {
    this.currentScreenStatusInfo = {};
    let mainWindow: window.Window = GlobalConfig.get(GLOBAL_CONFIG_KEY_WINDOW) as window.Window;
    mainWindow.on('windowSizeChange', (windowSize: Size) => this.screenUIChangeAdapter());
    mainWindow.on("avoidAreaChange", (options: window.AvoidAreaOptions) => this.avoidAreaChangeAdapter(options));
    mainWindow.on("windowStatusChange", (type: window.WindowStatusType) => this.windowStatusTypeChangeAdapter(type));
    mainWindow.on("windowRectChange", (options: window.RectChangeOptions) => this.windowSizeChangeAdapter(options));
  }

  /** 初始化，一般在EntryAbility获取到当前window对象后调用 */
  public static init() {
    if (ScreenObserver.mInstance) {
      return;
    }
    ScreenObserver.mInstance = new ScreenObserver();
  }

  /**
   * 在当前UI上下文中订阅屏幕状态改变事件。
   * @param uiContext 当前UI上下文。
   * @param subscriber 屏幕状态改变事件，与当前UI上下文相关。
   */
  public static subscribe(uiContext: UIContext, subscriber: Callback<ScreenStatusInfo, void>) {
    ScreenObserver.init();
    ScreenObserver.mInstance.subscribers.set(uiContext, subscriber);
  }

  /**
   * 取消当前UI上下文中屏幕状态改变事件的订阅。
   * @param uiContext 当前UI上下文。
   */
  public static unsubscribe(uiContext: UIContext) {
    ScreenObserver.init();
    ScreenObserver.mInstance.subscribers.remove(uiContext);
  }

  /* ---------- 子项监听。 ---------- */

  /** 响应设备类型的变化。 */
  private screenUIChangeAdapter() {
    let newScreenUIType = getScreenUIType();
    let changed: boolean = this.currentScreenStatusInfo.screenUIType !== newScreenUIType;
    if (changed) {
      this.currentScreenStatusInfo.screenUIType = newScreenUIType;
      this.subscribers.forEach((callback: Callback<ScreenStatusInfo, void>, uiContext: UIContext) => {
        try {
          callback(this.currentScreenStatusInfo);
        } catch (error) {}
      });
    }
  }

  /**
   * 响应安全区的变化。
   * @param options 新的安全区信息。
   */
  private avoidAreaChangeAdapter(options: window.AvoidAreaOptions) {
    let newAvoidAreaType = options.type;
    let newAvoidArea = options.area;
    let changed: boolean = this.currentScreenStatusInfo.avoidAreaType !== newAvoidAreaType ||
      this.currentScreenStatusInfo.avoidArea?.visible !== newAvoidArea.visible ||
      diffRect(this.currentScreenStatusInfo.avoidArea.leftRect, newAvoidArea.leftRect) ||
      diffRect(this.currentScreenStatusInfo.avoidArea.topRect, newAvoidArea.topRect) ||
      diffRect(this.currentScreenStatusInfo.avoidArea.rightRect, newAvoidArea.rightRect) ||
      diffRect(this.currentScreenStatusInfo.avoidArea.bottomRect, newAvoidArea.bottomRect);
    if (changed) {
      this.currentScreenStatusInfo.avoidAreaType = newAvoidAreaType;
      this.currentScreenStatusInfo.avoidArea = newAvoidArea;
      this.subscribers.forEach((callback: Callback<ScreenStatusInfo, void>, uiContext: UIContext) => {
        try {
          callback(this.currentScreenStatusInfo);
        } catch (error) {}
      });
    }
  }
  
  /**
   * 响应屏幕状态类型的改变。
   * @param type 新的屏幕状态类型。
   */
  private windowStatusTypeChangeAdapter(type: window.WindowStatusType) {
    let newType = type;
    let changed: boolean = this.currentScreenStatusInfo.windowStatusType !== newType;
    if (changed) {
      this.currentScreenStatusInfo.windowStatusType = newType;
      this.subscribers.forEach((callback: Callback<ScreenStatusInfo, void>, uiContext: UIContext) => {
        try {
          callback(this.currentScreenStatusInfo);
        } catch (error) {}
      });
    }
  }

  /**
   * 响应屏幕断点的改变。
   * @param options 新的屏幕尺寸信息。
   */
  private windowSizeChangeAdapter(options: window.RectChangeOptions) {
    let oldWindowWidthBreakpoint = this.currentScreenStatusInfo.windowWidthBreakpoint;
    let oldWindowHeightBreakpoint = this.currentScreenStatusInfo.windowHeightBreakpoint;
    this.subscribers.forEach((callback: Callback<ScreenStatusInfo, void>, uiContext: UIContext) => {
      let newWindowWidthBreakpoint = uiContext.getWindowWidthBreakpoint();
      let newWindowHeightBreakpoint = uiContext.getWindowHeightBreakpoint();
      let changed: boolean = oldWindowWidthBreakpoint !== newWindowWidthBreakpoint || oldWindowHeightBreakpoint !== newWindowHeightBreakpoint;
      if (changed) {
        this.currentScreenStatusInfo.windowWidthBreakpoint = newWindowWidthBreakpoint;
        this.currentScreenStatusInfo.windowHeightBreakpoint = newWindowHeightBreakpoint;
        try {
          callback(this.currentScreenStatusInfo);
        } catch (error) {}
      }
    });
  }
}
```

#### 使用

1，在EntryAbility中初始化：

```text
onWindowStageCreate(windowStage: window.WindowStage): void {
  ...
  windowStage.loadContent('pages/splashscreen/SplashScreen', (err) => {
    ...
    // 初始化屏幕状态监控。
    ScreenObserver.init();
  });
  ...
}
```

2，在页面的aboutToAppear中，或者onReady中订阅屏幕状态监控：

```text
ScreenObserver.subscribe(this.getUIContext(), (screenStatus: ScreenStatusInfo) => {
  if (screenStatus.avoidArea !== undefined) {
    if (screenStatus.avoidAreaType === window.AvoidAreaType.TYPE_SYSTEM) {
      // 触发顶部安全区改变。
      this.topSafeZoneHeightVp = px2vp(screenStatus.avoidArea.topRect.height);
    } else if (screenStatus.avoidAreaType === window.AvoidAreaType.TYPE_NAVIGATION_INDICATOR) {
      // 触发底部安全区改变。
      this.bottomSafeZoneHeightVp = px2vp(screenStatus.avoidArea.bottomRect.height);
    }
  }
  // 还可以监听其他状态的改变...
});
```

3，在页面的aboutToDisappear中，或者onDisAppear中取消订阅：

```text
ScreenObserver.unsubscribe(this.getUIContext());
```
