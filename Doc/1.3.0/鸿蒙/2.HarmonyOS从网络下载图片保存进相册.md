# HarmonyOS从网络下载图片保存进相册

#### 概述

现在有如下需求：Image组件显示了一张网络图片，我们要设法把这张网络图片下载至系统相册内。

当需要操作系统相册时，我们有两个方案：

- 方案A：为应用申请ohos.permission.WRITE_IMAGEVIDEO权限，后续会有权限申请框的弹出、图片保存等操作；
- 方案B：使用SaveButton按钮。

这次我们选择方案B。在这个方案中，SaveButton被按下后，将会临时有10秒时间允许操作系统相册。但是如果网络环境不佳，可能把图片从网上拽下来就会超过10秒。因此我们把整个图片的保存过程分成两步：

- 在页面上安排一个下载按钮，或点击图片下载。点击下载按钮后，展示一个弹窗，同时先把图片位图信息从网上下载下来(这个步骤不需要权限)。
- 图片位图信息下载完成后，再展示SaveButton。点击SaveButton后执行把位图信息写入相册的操作。

#### 操作步骤

##### 一、下载位图信息

这个步骤比较简单，假设图片的网络地址是netPhotoUrl，代码如下：

```text
/** 网络图片数据。 */
private photoData: ArrayBuffer | undefined = undefined;

/** 准备图片数据。 */
private preparing() {
  http.createHttp().request(netPhotoUrl)
    .then((response: http.HttpResponse) => {
      if (response.result instanceof ArrayBuffer) {
        this.photoData = response.result;
      }
    })
    .catch(() => 异常处理)
}
```

##### 二、操作SaveButton

上一步中我们已经获得了photoData，类型是ArrayBuffer(位图信息)，这样当点击SaveButton按钮时，就可以将此位图信息写入系统相册了：

首先还是定义一下保存图片后的结果信息：

```text
/** 复制文件结果。 */
export interface CopyFileResult {
  /** 复制文件结果Uri。 */
  resultUri: string
}
```

保存方法：

```text
/**
 * 保存一张图片至系统相册。<br />
 * 注：需要得到图片的位图数据再调用此方法。
 * 1，如果使用SaveButton控件，需要保证10秒内完成图片位图数据的存储。
 * 2，如果不使用SaveButton控件，需要额外申请ohos.permission.WRITE_IMAGEVIDEO权限。
 * @param context UI上下文。
 * @param buffer 图片位图数据。
 */
public static saveOnePhotoToGallery(context: common.UIAbilityContext, buffer: ArrayBuffer): Promise<CopyFileResult | undefined> {
  return new Promise((resolve, reject) => {
    let helper: photoAccessHelper.PhotoAccessHelper = photoAccessHelper.getPhotoAccessHelper(context);
    helper.createAsset(photoAccessHelper.PhotoType.IMAGE, 'jpg') // 先保存成jpg，当然也可指定其他格式。
      .then((targetFileUri: string) => {
        let file: fs.File | undefined = undefined;
        try {
          file = fs.openSync(targetFileUri, fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE);
          fs.writeSync(file.fd, buffer);
          let copyResult: CopyFileResult = {
            resultUri: targetFileUri
          };
          resolve(copyResult);
        } catch (error) {
          reject(error);
        } finally {
          if (file !== undefined) {
            fs.closeSync(file);
          }
        }
      })
      .catch((error: BusinessError) => reject(error));
  });
}
```

这个方法已加入[PhotoPickerUtils.ets](../../../MyCookBook_HarmonyOS/entry/src/main/ets/utils/common/mediapicker/PhotoPickerUtils.ets)。

##### 三、封装对话框

就像在概述中说的，我们要封装一个对话框，在这个对话框中进行图片位图信息的下载、展示SaveButton等动作。这个对话框内容如下：

```text
/** 页面显示状态。 */
enum PAGE_STATUS {
  /** 准备中。 */ PREPARING,
  /** 准备成功。 */ PREPARE_SUCCESS,
  /** 准备失败。 */ PREPARE_FAILURE,
  /** 保存中。 */ SAVING
}

@Component
export struct PhotoDownloadDialog {

  /** 网络图片地址。 */
  netPhotoUrl: string = ''

  /** 网络图片数据。 */
  private photoData: ArrayBuffer | undefined = undefined;

  /** 页面加载状态。 */
  @State pageStatus: PAGE_STATUS = PAGE_STATUS.PREPARING;

  aboutToAppear(): void {
    this.preparing();
  }

  build() {
    Column() {
      Text(
        this.pageStatus === PAGE_STATUS.PREPARING ? '正在准备...' :
        this.pageStatus === PAGE_STATUS.PREPARE_SUCCESS ? '准备成功' :
        this.pageStatus === PAGE_STATUS.PREPARE_FAILURE ? '准备失败' :
        '正在保存'
      )
        .width('100%')
        .textAlign(TextAlign.Center)
        .padding(12)
      if (this.pageStatus === PAGE_STATUS.PREPARE_SUCCESS) {
        Row() {
          SaveButton()
            .fontSize(14) // SaveButton本身还有很多样式可以设置。
            .onClick((event: ClickEvent, result: SaveButtonOnClickResult, error?: BusinessError<void>) => {
              this.pageStatus = PAGE_STATUS.SAVING;
              if (this.photoData !== undefined) {
                PhotoPickerUtils.saveOnePhotoToGallery(this.photoData)
                  .then((result?: CopyFileResult) => {
                    if (result && result.resultUri !== undefined && result.resultUri.length > 0) {
                      promptAction.showToast({
                        message: '图片已保存至：' + result.resultUri
                      });
                    } else {
                      promptAction.showToast({
                        message: '保存失败'
                      });
                    }
                  })
                  .catch(() => promptAction.showToast({
                    message: '保存失败'
                  }))
              } else {
                promptAction.showToast({
                  message: '保存失败'
                });
              }
              // 关闭对话框。
            })
        }
        .margin({ bottom: 12 })
      } else if (this.pageStatus === PAGE_STATUS.PREPARE_FAILURE) {
        Image(重试按钮图标)
          .width(48)
          .height(48)
          .padding(12)
          .objectFit(ImageFit.Contain)
          .onClick((event: ClickEvent) => this.preparing())
      }
    }
    .width(320)
    .constraintSize({ maxHeight: 480 })
    .justifyContent(FlexAlign.Start)
    .alignItems(HorizontalAlign.Center)
    .backgroundColor(Color.White)
    .border({ radius: 12 })
  }

  /** 准备图片数据。 */
  private preparing() {
    this.pageStatus = PAGE_STATUS.PREPARING;
    http.createHttp().request(this.netPhotoUrl)
      .then((response: http.HttpResponse) => {
        if (response.result instanceof ArrayBuffer) {
          this.photoData = response.result;
          this.pageStatus = PAGE_STATUS.PREPARE_SUCCESS;
        } else {
          this.pageStatus = PAGE_STATUS.PREPARE_FAILURE;
        }
      })
      .catch(() => this.pageStatus = PAGE_STATUS.PREPARE_FAILURE)
  }
}
```

将这个PhotoDownloadDialog作为弹窗内容弹出即可，网络图片地址信息(netPhotoUrl)需要从外部传入。
