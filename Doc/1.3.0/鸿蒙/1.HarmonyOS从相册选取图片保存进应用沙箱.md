# HarmonyOS从相册选取图片保存进应用沙箱

#### 概述

全部流程包括三个步骤：

- 使用photoAccessHelper.PhotoViewPicker选取图片；
- 处理图片的方向问题；
- 将处理完毕的图片保存至应用沙箱中。

鉴于这个流程比较常用，我们可以封装一个工具类，比如叫`PhotoPickerUtils`。

#### 操作步骤

##### 一、选取图片

选取图片使用photoAccessHelper.PhotoViewPicker即可，可以选取一张，也可以选取多张。我们先定义一个选取图片方法的入参类型：

```text
export interface PickPhotoOptions {
  /** 最多选取图片张数，默认选取一张。 */
  maxSelectNumber?: number
}
```

具体的图片选取方法如下：

```text
/**
 * 选取图片。
 * @param options 入参。
 */
public static pickPhotoFromGallery(options?: PickPhotoOptions): Promise<photoAccessHelper.PhotoSelectResult | undefined> {
  return new Promise((resolve, reject) => {
    let photoPicker: photoAccessHelper.PhotoViewPicker = new photoAccessHelper.PhotoViewPicker();
    photoPicker.select({
      MIMEType: photoAccessHelper.PhotoViewMIMETypes.IMAGE_TYPE,
      maxSelectNumber: options?.maxSelectNumber !== undefined ? Math.max(1, options.maxSelectNumber) : 1,
      isSearchSupported: true, // 支持按关键字搜索图片。
      isPhotoTakingSupported: true, // 支持拍照获取图片。
    })
      .then((pickResult: photoAccessHelper.PhotoSelectResult) => resolve(pickResult))
      .catch((error: BusinessError) => reject(error));
  });
}
```

photoAccessHelper.PhotoViewPicker.select提供了很多选项，可以点进去查看下。

##### 二、处理图片的方向问题

某些图片自带方向信息，且这个方向不是正向的，如果有需要的话，我们也得处理一下图片的初始方向问题，把图片回正。

1，首先我们取出图片的所有属性信息：

```text
/**
 * 获取图片属性。
 * @param sourceImg 源图文件对象。
 * @return 属性集合。
 */
private static getPhotoProperties(sourceImg: image.ImageSource): Record<string, string | undefined> {
  let result: Record<string, string | undefined> = {};
  Object.keys(image.PropertyKey).forEach((propertyKeyStr: string) => {
    let propertyKey: image.PropertyKey = image.PropertyKey[propertyKeyStr];
    try {
      let propertyValue: string = sourceImg.getImagePropertySync(propertyKey);
      result[propertyKey] = propertyValue;
    } catch (error) {
      result[propertyKey] = undefined;
    }
  });
  return result;
}
```

2，处理图片方向问题：

上述图片属性信息中，“Orientation”标记了图片的初始方向，这个key的常量值是image.PropertyKey.ORIENTATION。我们就使用这个key来拿出图片的初始方向信息：


图片保存完成后的结果参数定义如下：

```text
/** 复制文件结果。 */
export interface CopyFileResult {
  /** 复制文件结果Uri。 */
  resultUri: string

```

先进行图片方向的回正：

```text
/**
 * 调整图片方向，并存储图片至应用沙箱。
 * @param options 入参。
 */
private static adjustOrientationAndSavePhotoToAPP(options: AdjustOrientationAndSavePhotoOptions): Promise<CopyFileResult | undefined> {
  return new Promise(async (resolve, reject) => {
    let pixelMap: PixelMap | undefined = undefined;
    try {
      pixelMap = options.sourceImg.createPixelMapSync();
      switch (options.sourceOrientation) {
        case "Top-right": pixelMap.flipSync(true, false); break;
        case "Bottom-right": pixelMap.rotateSync(-180); break;
        case "Bottom-left": pixelMap.flipSync(false, true); break;
        case "Left-top": pixelMap.rotateSync(-270); pixelMap.flipSync(true, false); break;
        case "Right-top": pixelMap.rotateSync(-90); break;
        case "Right-bottom": pixelMap.rotateSync(-90); pixelMap.flipSync(true, false); break;
        case "Left-bottom": pixelMap.rotateSync(-270); break;
        default:
          break;
      }
      let copyResult: CopyFileResult | undefined = await PhotoPickerUtils.savePixelMapToAPPSync({
        sourceFileMimeType: options.sourceFileMimeType,
        sourceFileName: options.sourceFileName,
        targetPath: options.targetPath,
        sourcePixelMap: pixelMap
      });
      resolve(copyResult);
    } catch (error) {
      try {
        let copyResult: CopyFileResult | undefined = copyFileSync({
          sourceUri: options.sourceUri,
          targetPath: options.targetPath
        });
        resolve(copyResult);
      } catch (error) {
        reject(error);
      }
    } finally {
      if (pixelMap !== undefined) {
        pixelMap.release();
      }
    }
  });
}
```

##### 三、保存图片

1，上述代码中PhotoPickerUtils.savePixelMapToAPPSync方法用来将回正后的图片保存进应用沙箱：

```text
/**
 * 同步存储位图信息至应用沙箱。
 * @param options 入参。
 */
private static async savePixelMapToAPPSync(options: SavePixelMapOptions): Promise<CopyFileResult | undefined> {
  let imagePacker: image.ImagePacker | undefined = undefined;
  let targetFile: fs.File | undefined = undefined;
  try {
    imagePacker = image.createImagePacker();
    let sourceFileName: string = options.sourceFileName; // 源文件名。
    let separator: string = options.targetPath.endsWith('/') ? '' : '/'; // 文件路径分隔符。
    let targetFileUri: string = `${options.targetPath}${separator}Copy${new Date().getTime()}_${sourceFileName}`; // 目标文件Uri。
    targetFile = fs.openSync(targetFileUri, fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE);
    await imagePacker.packToFile(options.sourcePixelMap, targetFile.fd, {
      format: options.sourceFileMimeType,
      quality: 100
    });
    let copyResult: CopyFileResult = {
      resultUri: targetFileUri
    };
    return copyResult;
  } catch (error) {
    return undefined;
  } finally {
    if (targetFile !== undefined) {
      fs.closeSync(targetFile);
    }
    if (imagePacker !== undefined) {
      imagePacker.release();
    }
  }
}
```

2，如果图片不含方向信息，即getPhotoProperties方法没有拿出“Orientation”属性值的场景，使用普通的文件IO保存图片即可：

(这里提供同步和异步两个方法)

```text
/** 复制图片入参。 */
export interface CopyFileOptions {
  /** 源文件Uri。 */
  sourceUri: string,
  /** 目标路径。 */
  targetPath: string
}
```

```text
/**
 * 复制文件。
 * @param options 入参。
 */
export function copyFile(options: CopyFileOptions): Promise<CopyFileResult | undefined> {
  return new Promise((resolve, reject) => {
    try {
      let copyResult: CopyFileResult | undefined = copyFileSync(options);
      resolve(copyResult);
    } catch (error) {
      reject(error);
    }
  });
}
```

```text
/**
 * 复制文件(同步方法)。
 * @param options 入参。
 * @returns 复制结果。
 * @throws 复制过程中会出现异常，须捕获。
 */
export function copyFileSync(options: CopyFileOptions): CopyFileResult | undefined {
  let sourceFile: fs.File | undefined = undefined;
  let targetFile: fs.File | undefined = undefined;
  try {
    sourceFile = fs.openSync(options.sourceUri, fs.OpenMode.READ_ONLY);
    let sourceFileName: string = sourceFile.name; // 源文件名。
    let separator: string = options.targetPath.endsWith('/') ? '' : '/'; // 文件路径分隔符。
    let targetFileUri: string =
      `${options.targetPath}${separator}Copy${new Date().getTime()}_${sourceFileName}`; // 目标文件Uri。
    targetFile = fs.openSync(targetFileUri, fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE);
    fs.copyFileSync(sourceFile.fd, targetFile.fd);
    let copyResult: CopyFileResult = {
      resultUri: targetFileUri
    };
    return copyResult;
  } catch (error) {
    throw new Error(error);
  } finally {
    if (sourceFile !== undefined) {
      fs.closeSync(sourceFile);
    }
    if (targetFile !== undefined) {
      fs.closeSync(targetFile);
    }
  }
}
```

#### 流程总结

以上就是从相册选取图片保存进应用沙箱所用到的工具方法了。从中可以看出，如果对图片进行了方向回正操作，那么在保存图片时，操作的是图片的位图信息(savePixelMapToAPPSync中使用imagePacker打包位图进文件)；如果不需要对图片进行回正操作，那么保存文件时，使用普通文件IO即可。

整体流程可表示如下：

```text
[从相册中选取图片]
       ↓
[判断图片原始方向]
       ↓
<需调整图片方向？> N → [使用文件IO保存图片]
      Y↓
[调整图片回正方向]
       ↓
[打包位图进沙箱中]
```

这个工具类代码位于[PhotoPickerUtils.ets](../../../MyCookBook_HarmonyOS/entry/src/main/ets/utils/common/mediapicker/PhotoPickerUtils.ets)。

#### 调用

设想我们有如下需求：单击按钮从相册选取N张图片，把它们调整好方向后存入应用沙箱，并使用N个Image组件来显示。

对于选出的每一张图片，“调整方向+存入沙箱”都是耗时的操作，因此我们要对这么多原始图片同时启动“调整方向+存入沙箱”。为了保证所有图片的操作都能兼顾到，不会因为某一张图片操作失败导致其他图片的操作中断，我们使用Promise.allSettled方法。

封装好的调用过程如下：

```text
/**
 * 选取图片。
 * @param maxSelectNumber 最多选取图片张数，默认选取一张。
 */
function pickPhoto(maxSelectNumber: number) {
  PhotoPickerUtils.pickPhotoFromGallery({
    maxSelectNumber: maxSelectNumber
  })
    .then((pickResult?: photoAccessHelper.PhotoSelectResult) => {
      if (pickResult === undefined) {
        // 没有选取任何照片，退出。
        return;
      }
      // 将图片移动至应用沙箱中，再返回沙箱对应路径。
      Promise.allSettled(pickResult.photoUris.map((sourceUri: string) => {
        return PhotoPickerUtils.saveOnePhotoToAPP({
          sourceUri: sourceUri,
          targetPath: context.filesDir + "/" + path // 记得事先创建好这个“path”文件夹。
        });
      }))
        .then((copyResults: PromiseSettledResult<CopyFileResult | undefined>[]) => {
          let resultUris: string[] = [];
          copyResults.forEach((resultItem: PromiseSettledResult<CopyFileResult | undefined>) => {
            if (resultItem.status === "fulfilled" && resultItem.value !== undefined) {
              resultUris.push(resultItem.value.resultUri);
            }
          });
          // resultUris就是保存好的沙箱内所有图片Uri，将这些Uri赋值给对应Image组件即可。
        })
        .catch(() => 异常处理)
    })
    .catch(() => 异常处理)
}
```
