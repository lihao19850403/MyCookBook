# 1.0.0版本应用测试

#### 介绍
应用使用ArkXTest框架进行项目测试，相关代码位于[entry/src/ohosTest/ets/test/](./entry/src/ohosTest/ets/test)文件夹。

#### 头条测试

1.  BootTest：应用启动测试。
2.  titleTest：测试能否切换至头条Tab页。
3.  listTest：测试是否加载出了新闻内容，以及跳转至新闻详情，并跳转至原文链接。

---

#### 菜谱测试

1.  BootTest：应用启动测试。
2.  titleTest：测试能否切换至菜谱Tab页。
3.  recommendListTest：测试能否加载出推荐菜谱内容，以及跳转至推荐菜谱列表，并加入一条菜谱信息到收藏夹。
4.  favoriteListTest：测试能否跳转值菜谱详情，并正常跳转至菜谱大图。

---

#### 美食圈测试

1.  BootTest：应用启动测试。
2.  titleTest：测试能否切换至美食圈Tab页。
3.  webViewTest：测试内置浏览器是否正常加载。

---

#### “我的”页面测试

1.  BootTest：应用启动测试。
2.  titleTest：测试能否切换至“我的”Tab页。
3.  healthyTipsTest：测试每日养生是否正常加载。
4.  appFirstPageTest：测试切换应用首页的选项是否能够被点击。
5.  textSizeTest：测试字号设置选项是否工作正常。
6.  splitScreenTest：测试分屏显示按钮是否可点击。
7.  jumpToFavoriteMenusTest：测试能否跳转至菜谱Tab页。
